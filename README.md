# 林鶴明｜三立集團電子名片

正式網址：https://sidney-businesscard.netlify.app/

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 電子名片網頁本體（版面、連結、分頁切換） |
| `intro.mp4` | 個人簡介影片（直式，20 秒） |
| `setv.mp4` | 三立集團企業日形象影片（橫式，720p，2 分 13 秒） |
| `setv_poster.jpg` | 三立影片封面 |
| `sidney-lin.vcf` | 「存入通訊錄」下載的聯絡人檔（含大頭照） |
| `_headers` | Netlify 設定：讓手機正確辨識 .vcf 通訊錄檔 |

## 更新方式

修改檔案並推送到 `main` 分支後，Netlify 會自動重新部署，網址與 QR Code 不變。

## 後續規劃

作為三立業務部電子名片的範本：替換照片、姓名職稱、聯絡方式與 `sidney-lin.vcf`，即可產出同仁專屬名片。
